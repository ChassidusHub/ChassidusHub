Twenty parts build every page

Each part has one job and the same states everywhere: rest, hover, pressed, focus, disabled and busy. Focus is always a 2px accent ring with a 2px gap.

Button

Kinds: primary (at most one per view), default, quiet, danger and icon (which always has a label for screen readers). Height is 36px, or 44px on a touch screen.

Field & search

This is shown on your suggestions and reports.

The label always sits above the field and help text below it. An error replaces the help text in red, with a word that says what to do. The search box opens the command palette.

Choice: toggle, segmented, select

Frank Ruehl

Toggle is for on or off. Segmented is for two to four choices you can see. Select is for five or more. A choice takes effect at once and needs no Save.

Status pills (round) say where a suggestion or report stands. Labels (square) say what kind of thing an item is. The two never mix.

A row has an optional start (a cover, an icon or an avatar), a title and a line under it, then an end (a value, a control or a chevron). Lists, menus and settings are all built from rows.

There is one ⋯ menu per page, always in the same corner. Its groups follow the levels: This page for everyone, Help once you help, and Steward once you steward. Each item has a keyboard shortcut, so the command palette can find it too.
